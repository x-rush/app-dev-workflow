# 原型阶段详细规范

## 情绪板（Moodboard）做法

产出"气质拼贴"：风格关键词、色板（**具体色值**）、字体气质、质感参照、可选的产品隐喻（"像一份银行对账单"/"像运动手表表盘"）。

- 工具：纯 CSS 拼板（零图片依赖），单文件 HTML 展示；
- 同一产品可出 2~3 块方向板（气质截然不同）让用户挑，挑定后再写界面；
- 情绪板是后续所有取色、字号、文案语气、生图 prompt 的出处——没有它不许写界面。

## HTML 原型标准

- 真实中文文案（不用 Lorem ipsum）、可点击跳转、响应式适配（手机/桌面）；
- App 原型用手机壳包裹（390×844 基准），状态栏/灵动岛/tab 栏等框架元素完整；
- 每个颜色、字号、间距从情绪板取值；
- 图标首选手写 SVG 线条风起步，确需插画级素材再走生图（先过生图前置确认）；
- 交付前自测：浏览器打开、程序化检查（图片加载、内容溢出、横向滚动）+ 截图视觉审查。

## 生图规范（fal.ai，经 art-gen skill 调用）

| 用途 | 何时用 | 模型/成本 | 注意 |
|---|---|---|---|
| 界面概念图 | 方向犹豫时，一次 2~3 张挑方向 | grok2 ~$0.07/张 | 文字乱码属正常；只看布局配色方向 |
| 产品素材（图标/插画/吉祥物） | 界面确需、且风格经用户确认 | grok2 白底生成 + 程序抠图转透明 PNG | prompt 从情绪板翻译 |
| 氛围概念图 | 仅当用户点名要求 | 面向团队/客户的气质叙事场景；独立开发且无协作沟通需求时通常跳过 |

**生图前置确认（默认必做，个人/项目覆盖层可调整强度）**：先确认风格 → 先确认内容预期（图里有什么/没什么）→ 先确认数量。三项确认后再执行。

## 成本直觉

| 步骤 | 成本 | 何时花 |
|---|---|---|
| 情绪板 | 免费 | 每次都做，~10 分钟 |
| 界面概念图 | ~$0.07/张 | 方向犹豫才花；参考产品够清楚可跳过 |
| HTML 原型 | 免费 | 主线，反复投入 |
| 素材生图 | ~$0.07/张 | 界面真需要才花 |
