# 原型阶段详细规范

## 情绪板（Moodboard）做法

产出"气质拼贴"：风格关键词、色板（**具体色值**）、字体气质、质感参照、可选的产品隐喻（"像一份银行对账单"/"像运动手表表盘"）。

- 工具：纯 CSS 拼板（零图片依赖），单文件 HTML 展示；
- 同一产品可出 2~3 块方向板（气质截然不同）让用户挑，挑定后再写界面；
- 情绪板是后续所有取色、字号、文案语气、生图 prompt 的出处——没有它不许写界面。

## HTML 原型标准

- 真实中文文案（不用 Lorem ipsum）、可点击跳转、响应式适配（手机/桌面）；
- App 原型用手机壳包裹（390×844 基准），状态栏/灵动岛/tab 栏等框架元素完整；
- 每个颜色、字号、间距从情绪板取值；
- 图标首选手写 SVG 线条风起步，确需插画级素材再走生图（先过生图前置确认）；
- 交付前自测：浏览器打开、程序化检查（图片加载、内容溢出、横向滚动）+ 截图视觉审查。

## "AI 味"自检清单（两遍设计法）

第一遍：出紧凑 token 计划——4~6 个命名色值、字体及角色、布局概念（可 ASCII 线框）、设计原则一句话。第二遍：**先自审再写码**——对每个视觉决定问"这是不是我对任何类似 brief 都会生成的默认？"是就换。

默认套路黑名单（源自 Anthropic 官方 frontend-design，无主题依据地出现即换）：

- 米白底（≈#F4F1EA）+ 高对比衬线大标题 + 陶土色强调（≈#D97757）；
- 近黑底 + 单一酸性绿/朱红强调；
- SaaS 卡片全家桶：内容切成同款圆角卡片、不分层级统一圆角、每张同款灰色阴影、渐变横幅当装饰；
- 模板 chrome：标题上一律全大写 eyebrow 小标、元信息中点连接（A · B · C）、"词 — 短语"式标签、按钮尾巴加 →；
- 动效默认：每段 fade-and-slide-up 入场、每卡片 hover 过渡。

原则：**大胆只花在一处**——让一个元素成为记忆点，其余安静克制（Chanel 建议：出门前照镜子，摘掉一件配饰）。这些特征本身合法，问题是"无论主题是什么都长这样"——设计要从主题的行业/材质/语汇里长出来（8 岁女孩的玩具 ≠ 金融分析师的仪表盘）。

## 生图决策（流程层——只定"何时用"）

| 用途 | 何时用 | 要点 |
|---|---|---|
| 界面概念图 | 方向犹豫时，一次 2~3 张挑方向 | 文字乱码属正常；只看布局配色方向，看完即弃 |
| 产品素材（图标/插画/吉祥物） | 界面确需、风格经确认后 | prompt 从情绪板翻译 |
| 氛围概念图 | 仅协作叙事场景（团队/客户气质对齐） | 独立开发且无此需求时跳过；不画界面元素 |

**执行与预算管控委托**：模型选择、前置确认细则、预算/余额管理由所在环境的生图 skill 或工具负责（如有）；没有的环境可手动遵守总纪律 2 的三项确认，或安装开源生图 skill [image-forge](https://github.com/x-rush/image-forge)（多提供商引擎，自带前置确认与花费预算）。本流程不依赖任何具体生图工具——此为可选搭配，非必需。

## 成本直觉

| 步骤 | 成本 | 何时花 |
|---|---|---|
| 情绪板 | 免费 | 每次都做，~10 分钟 |
| 界面概念图 | 每张几美分量级 | 方向犹豫才花；参考产品够清楚可跳过 |
| HTML 原型 | 免费 | 主线，反复投入 |
| 素材生图 | 每张几美分量级 | 界面真需要才花 |

## 参考实现（由用户自沉淀）

**本 skill 不内置示例**——好设计因人/因项目而异，作者预设的"标准答案"反而会污染用户的审美方向。改为用户自沉淀机制：

- **沉淀位置**：`<skill>/MY-EXAMPLES/`（个人级，放你验收过的得意之作）或项目 `docs/examples/`（项目级）；
- **沉淀时机**：每次项目验收通过后，复盘时顺手判断——"这次的原型/情绪板值得当以后的参考吗？"值得就拷一份进去；
- **使用方式**：阶段 1 开工前，先看一眼沉淀库里有没有自己的旧作——有，按它的气质延续；没有，按情绪板 + AI 味自检从零定调；
- **同样适用于团队**：把团队公认的标杆界面放进项目 `docs/examples/`，就是最直接的"设计规范"。

升级版示例（更强、更通用）会随 skill 版本更新提供，届时在版本历史中说明。
